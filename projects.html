Stego Suite

A multi-format steganography toolkit for hiding data in images, audio and video using LSB encoding. It does not include encryption.

  • C++
  • Python
  • LSB encoding
  • FFmpeg
  • Image steganography: hides any file inside a PNG using the RGB channels, with a custom header for reliable extraction

Zero-Shot Low-Light Image Enhancement (published research)

A CLIP-guided semantic diffusion pipeline that brightens low-light images with no paired training data and no fine-tuning, with a Gradio demo hosted on Colab.

  • PyTorch
  • Stable Diffusion v1.5
  • CLIP
  • Gradio
  • Semantic guidance: CLIP ViT-B/32 steers Stable Diffusion v1.5
  • Consistency filter: rejects outputs that drift from the scene (CLIP cosine similarity above 0.85)
  • Faster sampling: DDIM and FP16 cut sampling from 1000 steps to 40-50
  • Evaluation: LOL and ExDark with PSNR, SSIM, LPIPS and MUSIQ: 15.56 dB and 0.729 SSIM vs 15.40 dB and 0.515 for a retinex baseline, on the evaluated samples
View source on GitHub
